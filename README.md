# مستودعات السلي — Sulay Warehouses

موقع تسويقي من صفحة واحدة (عربي RTL) لمشروع مستودعات السلي للبيع في شمال السلي بالرياض. المسوّق الحصري: القمم للعقارات.

## النشر
موقع ثابت بالكامل (HTML + CSS + JS بدون إطار ولا خطوة بناء). يُنشر على Vercel مباشرة من جذر المستودع بدون أي إعدادات.
`vercel.json` يضبط التخزين المؤقت، و`.vercelignore` يستبعد `brief/` و`assets/` (مواد المصدر) من النشر.

## تعديل البيانات
كل البيانات القابلة للتغيير في **`config.js`**: الجوال وواتساب ونص الرسالة، ورخصة فال، ورقم ترخيص الإعلان ورابطه وصورة الباركود، ورابط خرائط قوقل والإحداثيات (تُستخدم في بيانات Schema.org)، ورابط الموقع.

> إذا تغيّر نطاق الموقع النهائي، حدّث أيضًا روابط `og:url` و`og:image` و`canonical` في رأس `index.html`، لأن واتساب يقرأها قبل تشغيل أي JavaScript.

## البنية
```
index.html          الصفحة
config.js           البيانات القابلة للتعديل
css/style.css       التصميم (ألوان الهوية في :root)
js/main.js          التفاعلات: العدادات، المسقط التفاعلي، المعرض، الأسئلة والمرافق، نموذج واتساب
img/                صور WebP/AVIF متعددة الأحجام (مولّدة)
fonts/              IBM Plex Sans Arabic + Barlow Condensed (مستضافة محليًا)
og.jpg, favicon.*   صورة المشاركة والأيقونات
scripts/            أدوات توليد الصور وصورة المشاركة
```

## تحديث رقم الإصدار (Cache busting) — مهم بعد كل تعديل
روابط `css/style.css` و`js/main.js` و`config.js` في `index.html` تحمل بصمة محتوى (`?v=...`) حتى لا يرى الزوار نسخة قديمة مخزنة في متصفحاتهم.
**بعد أي تعديل على هذه الملفات الثلاثة شغّل قبل الـ commit:**
```bash
python3 scripts/stamp_versions.py
```
السكربت يحسب بصمة كل ملف ويحدّثها في `index.html`، ولا يغيّر البصمة إلا إذا تغيّر محتوى الملف.

## إعادة توليد الصور
```bash
python3 scripts/build_images.py   # الصور من assets/ إلى img/
node scripts/render_static.js     # og.jpg والأيقونات (يتطلب Playwright)
```
